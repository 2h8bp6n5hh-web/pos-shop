# ร้านค้า POS — GitHub Pages / PWA

## วิธีติดตั้ง
1. สร้าง GitHub repository ใหม่ เช่น `pos-shop`
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดในชุดนี้ โดยให้ `index.html` อยู่ที่ root
3. ไปที่ **Settings → Pages**
4. เลือก **Deploy from a branch**
5. เลือก branch `main` และ folder `/ (root)` แล้วกด Save
6. รอ GitHub สร้างเว็บไซต์ จากนั้นเปิด URL ที่ได้ด้วย Safari

## ติดตั้งบน iPhone
เปิดเว็บไซต์ใน Safari → Share → **Add to Home Screen**

## หมายเหตุ
ข้อมูลสินค้า/สต็อก/ประวัติการขายของแอปนี้เก็บด้วย Local Storage ในอุปกรณ์/เบราว์เซอร์นั้น ไม่ได้ซิงก์ข้ามเครื่องหรือผู้ใช้
